常见问题

HEX 和 RGB 有什么区别？
两者表示的是同一种颜色，只是写法不同。HEX 用十六进制表示，如 #4F46E5；RGB 用三个 0~255 的分量表示，如 rgb(79, 70, 229)。本工具可以让它们实时互转。
HSL 和 HSV 是什么？
HSL 用色相（Hue）、饱和度（Saturation）、明度（Lightness）描述颜色；HSV（也叫 HSB）则用色相、饱和度、明度（Value/Brightness）。它们比 RGB 更符合人眼直觉，做配色调整时更方便。
怎么让文字在这个颜色上看得清？
看对比度即可。工具会根据颜色的相对亮度计算它与白色、黑色文字的 WCAG 对比度，并给出建议。一般来说对比度达到 4.5 : 1 以上，正文文字就算清晰可读。
转换会上传我的数据吗？
不会。所有颜色计算都在浏览器本地完成，不会发送到服务器。
