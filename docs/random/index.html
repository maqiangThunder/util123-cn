常见问题

这个随机数是真随机吗？
本工具使用浏览器内置的 crypto 安全随机数接口生成，足够用于抽签、决定、游戏等日常场景；但不适用于密码学密钥或赌博等对随机性要求极高的用途。
抽奖会重复抽中同一个人吗？
每点一次都是从当前名单里等概率抽取一个，可能和上次重复。如果希望不重复，抽完把抽中的那行删掉再抽即可。
生成过程会上传名单吗？
不会。名单和结果都在浏览器本地处理，不会发送到服务器。
