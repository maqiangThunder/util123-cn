常见问题

MD5 和 SHA-256 有什么区别？
MD5 输出 128 位（32 个十六进制字符），速度快但已被证明存在碰撞漏洞，不适合做安全校验；SHA-256 输出 256 位（64 个字符），安全性更高，常用于文件完整性校验和数字签名。
哈希（Hash）是加密吗？能还原原文吗？
不是加密，也不能还原。哈希是单向摘要算法，把任意长度内容变成固定长度的字符串；哪怕原文只改一个字符，结果也会完全不同。它用来校验完整性，不能据此反推原文。
可以用来校验下载文件是否被篡改吗？
可以。软件发布页通常会给出安装包的 SHA-256 值，你用本工具对下载下来的文件算一次哈希，与官方公布的值一致，就说明文件没被篡改或损坏。
计算哈希会上传我的文本或文件吗？
不会。所有计算都在浏览器本地完成，文本与文件都不会发送到服务器。
