常见问题

URL 编码（百分号编码）是做什么的？
网址里只能安全使用一部分 ASCII 字符，中文、空格、& # ? 等字符必须转换成 % 加十六进制的形式，这就是 URL 编码（urlencode），浏览器与服务端会再解码还原。
URI 组件和完整网址两种模式有什么区别？
URI 组件模式（encodeURIComponent）会把 / : ? & = # 等分隔符也一起编码，适合编码单个参数值；完整网址模式（encodeURI）会保留这些分隔符，适合编码整条网址。
网址里的 + 号是什么？
在查询字符串中 + 常被当作空格，而标准编码里空格应是 %20。本工具解码时按标准 %XX 处理，不会把 + 自动替换成空格，避免误伤真实内容。
解析参数会上传我的网址吗？
不会。编码、解码与参数解析全部在浏览器本地完成，网址不会发送到服务器（工具也不会去访问该网址）。
