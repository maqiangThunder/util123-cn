常见问题

会验证签名吗？
不会。本工具只做 base64url 解码，展示 Header 和 Payload 明文，不校验签名真伪，也不依赖密钥。验证签名请在你自己的服务端进行。
Token 会上传吗？
不会。所有解码都在浏览器本地完成，Token 不会发送到任何服务器。
能识别过期时间吗？
能。如果 Payload 里有 exp / iat / nbf 等时间字段（Unix 秒），会额外显示可读的本地时间并提示是否已过期。
