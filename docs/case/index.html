常见问题

驼峰、蛇形、短横分别是什么？
都是多词命名的写法：驼峰（camelCase）每个词首字母大写且连写无空格；蛇形（snake_case）全小写用下划线连接；短横（kebab-case）全小写用连字符连接。常见用于变量名、文件名、CSS 类名等。
中文会被转换吗？
大小写只作用于英文字母，中文、数字和标点保持原样。驼峰 / 蛇形 / 短横会以非字母数字字符作为词的边界来切分。
转换会上传文本吗？
不会。所有转换都在浏览器本地完成，文本不会发送到服务器。
