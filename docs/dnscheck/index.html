常见问题

DNS 检测是做什么的？
它会从多家不同的公共 DNS 服务器（阿里、腾讯、Google、Cloudflare）分别解析你的域名，把每个服务器返回的 IP 放在一起对比。如果所有服务器返回的 IP 都一样，说明域名解析已经稳定生效；如果不一样，往往意味着 DNS 尚未完全生效，或域名配置了分区域 / 分线解析。国内网络访问 Google、Cloudflare 常出现超时或连接失败，这时只对比成功返回结果的服务器即可，不代表域名解析异常。
为什么不同 DNS 服务器结果会不一样？
修改 DNS 记录（A 记录）后，各地 DNS 有缓存，需要等 TTL 过期才会更新，所以会出现一部分服务器还是旧 IP、一部分已经是新 IP 的情况。另外部分域名会按访问来源返回不同 IP（分线 / 智能解析），也会造成差异。
检测工具的数据从哪来？
工具在你的浏览器里直接调用各公共 DNS 的 DNS-over-HTTPS（DoH）接口来解析，不经过本站服务器。
