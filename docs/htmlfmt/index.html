HTML / CSS 格式化

挤在一行的代码，一键排得整整齐齐。纯前端，代码不出浏览器。

常见问题

格式化会把我写的内容上传吗？

不会。代码只在你的浏览器本地解析与排版，不会发送到任何服务器。

HTML 格式化支持哪些情况？

基于浏览器 DOM 重新生成带缩进的结构化 HTML，能正确处理嵌套标签、自闭合标签与文本节点；注释与 doctype 会被省略，仅用于日常排版美化。

CSS 格式化会改动我的选择器吗？

不会。工具只调整缩进与换行，不改变选择器、属性名与属性值的任何内容。
