常见问题

这个 JSON 格式化工具支持哪些功能？
格式化（美化）、压缩（Minify）、实时语法校验与错误定位、语法高亮、可折叠树形视图、键值搜索、键排序、自动修复常见语法错误、转 YAML / CSV / XML、中文与 Unicode 互转、转义与反转义、双栏 Diff 对比，以及 JSONPath 查询。
粘贴的 JSON 数据会被上传到服务器吗？
不会。所有解析、转换、对比都在你的浏览器本地完成，数据不出本机。
怎么把 JSON 转成 YAML、CSV 或 XML？
在输出区切换到 YAML / CSV / XML 标签页即可；中文与 Unicode 互转、转义与反转义在「更多」菜单中。
能处理多大的 JSON 文件？
取决于浏览器可用内存，一般几 MB 以内的 JSON 都能流畅格式化；超大文件建议先压缩或分段处理。
支持 JSONPath 查询吗？
支持。输入类似 $.store.book[0].title 的表达式即可从结果中提取指定节点。
