常见问题

摩斯电码里点和划分别代表什么？

点（·）是短音，划（—）是长音，时长约为 1:3。本工具输出时字母间用空格、单词间用三个空格分隔。

中文也能转摩斯码吗？

标准摩斯电码基于拉丁字母与数字。本工具处理字母、数字和常用标点；输入中文时会提示先转为拼音或英文再转换。

数据会上传吗？

不会。所有转换与播放都在浏览器本地完成，不发送任何数据。
