常见问题

怎么查看自己的公网 IP 地址？
打开 util123.cn/ip/ 即自动检测，页面顶部会显示你当前的公网 IPv4（或 IPv6）地址，点击 IP 即可一键复制。
IP 显示的地理位置准确吗？
基于公开 IP 归属地库定位，一般精确到城市，可能与你的实际所在地有一定偏差；使用代理、VPN 或公司专线时，显示的是出口 IP 的归属地。
查询 IP 会被记录或上传吗？
不会。检测由浏览器直接向公开 IP 接口发起，本站服务器不保存、不转发你的 IP 地址与设备信息。
为什么运营商显示的和我办宽带的运营商不一样？
若你通过代理、VPN、云主机或企业出口上网，出口 IP 会归属到机房或运营商骨干网络，因此显示的运营商可能与你办理的宽带不同。
支持 IPv6 吗？
支持。如果你的网络具备 IPv6 出口，页面会显示 IPv6 地址并标注「IP 版本 IPv6」；否则显示 IPv4。
能查询任意 IP 的归属地吗？
可以。在「查任意 IP 归属地」里输入任意一个 IPv4 或 IPv6 地址，即可查询其国家、省份、城市、运营商与 ASN 等归属地信息，基于公开 IP 归属地库，一般精确到城市。
