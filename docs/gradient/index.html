常见问题

CSS 里的角度是什么意思？

linear-gradient 的角度指渐变方向：0deg 从下到上，90deg 从左到右，135deg 从左上到右下。拖动滑块实时预览最直观。

怎么用到自己的网页里？

复制生成的 CSS，粘贴到任意元素的 background 属性即可，例如 background: linear-gradient(...);，按钮、横幅、卡片背景都适用。

数据会上传吗？

不会。选色、预览、复制全部在浏览器本地完成，不发送任何数据。
