日期差计算

输入两个日期时间，立即算出相差多少天、小时、分钟、秒，也能算距今天还有多久。纯前端，数据不出浏览器。

常见问题

日期差按什么时区算？

按你浏览器本地时区解析输入的日期时间，适合一般排期与倒计时；跨时区业务请以约定时区为准。

计算会上传日期吗？

不会。全部在浏览器本地完成，不发送任何数据。
