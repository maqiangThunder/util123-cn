常见问题

ASCII 码表包含哪些字符？

标准 ASCII 共 128 个码位（0–127）：0–31 与 127 是控制字符（换行 LF、回车 CR、制表符 TAB 等），32–126 是可打印字符（空格、标点、数字、字母）。

怎么查一个字符的编码？

在搜索框输入字符（如 @）、十进制（如 64）、十六进制（0x40 或 40）或控制字符名（如 LF），表格会即时过滤定位。

数据会上传吗？

不会。查询完全在浏览器本地完成，不发送任何数据。
