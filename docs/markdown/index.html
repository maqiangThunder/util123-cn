常见问题

这个 Markdown 工具会把我的内容上传吗？

不会。所有解析与渲染都在你的浏览器本地完成，文本不会发送到任何服务器。

支持哪些 Markdown 语法？

支持标题、加粗、斜体、行内代码与代码块、有序/无序列表、引用、链接、分割线等常见语法。

可以导出成 HTML 吗？

可以。预览区右上角有“复制 HTML”按钮，一键把渲染结果对应的 HTML 源码复制到剪贴板。
