常见问题

身份证号会被上传吗？
不会。解析全程在你的浏览器本地完成，身份证号码不会发送到任何服务器。
身份证前六位代表什么？
前六位是地址码，按 GB/T 2260 编码：前两位是省，中间两位是地市，后两位是区县。本工具依据编码表查出对应的省和地市。
最后一位校验码有什么用？
第 18 位是按 ISO 7064（MOD 11-2）算法算出的校验码，用于发现输入错误或伪造号码。本工具会重新计算并与你输入的最后一位比对。
