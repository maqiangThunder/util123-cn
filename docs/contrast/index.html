常见问题

WCAG 对比度多少算达标？

常规文本：AA ≥ 4.5:1，AAA ≥ 7:1；大号文本（≥18pt 或 ≥14pt 粗体）：AA ≥ 3:1，AAA ≥ 4.5:1。UI 组件与图形元素 AA 要求 ≥ 3:1。

对比度是怎么算的？

按 WCAG 2.x 公式：先算两色各自的相对亮度 L（sRGB 通道伽马展开后按 0.2126/0.7152/0.0722 加权），对比度 = (L亮 + 0.05) / (L暗 + 0.05)，范围 1:1 ~ 21:1。

数据会上传吗？

不会。计算完全在浏览器本地完成，不发送任何数据。
