常见问题

\uXXXX 这种写法是什么？
这是 Unicode 转义序列，常见于 JavaScript、JSON、Java 等语言的字符串里。其中 XXXX 是该字符码点的十六进制表示，例如「中」是 \u4e2d、「A」是 \u0041。本工具可以把中文转成这种写法，也能把这种写法还原成中文。
Unicode 和 UTF-8 有什么区别？
Unicode 是「字符到码点」的编号标准，给每个字符分配一个唯一编号（如 U+4E2D）；UTF-8 则是把这个编号存成字节的具体编码方式。本工具处理的是码点层面的 Unicode 表示，与文件的 UTF-8 编码是两回事。
HTML 实体又是什么？
HTML 实体是用 &# 开头的引用方式，用来在网页里表示特殊字符，例如 &#20013;（十进制）或 &#x4E2D;（十六进制）都表示「中」。本工具可以在中文与 HTML 实体之间双向转换。
转换会上传我的内容吗？
不会。所有编码解码都在浏览器本地完成，输入的内容不会发送到服务器。
