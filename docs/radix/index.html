常见问题

怎么把 16 进制转成 10 进制？
在输入框里填入十六进制数（例如 FF 或 0xFF），源进制选择「16」，结果区会实时显示对应的十进制值（255）。也可以直接粘贴带 0x 前缀的字符串，工具会自动识别为十六进制。
能转换很大的数字吗？
可以。本工具基于 JavaScript 的 BigInt，不受 64 位浮点数精度限制，几百位的大整数也能精确转换，不会出现末位变 0 的精度丢失。
什么是 0x、0b、0o 前缀？
它们是编程语言里表示进制的常见写法：0x 表示十六进制、0b 表示二进制、0o 表示八进制。本工具会自动识别这些前缀并采用对应进制，无需手动选择。
支持哪些进制？
支持 2 到 36 之间的任意进制。常见的二进制、八进制、十进制、十六进制会直接列出，你还可以在「更多进制」里填写任意目标进制查看结果。
