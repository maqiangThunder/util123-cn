常见问题

Base64 是加密吗？
不是。Base64 只是一种把二进制数据用 64 个可打印字符表示的编码方式，任何人都能直接还原，不能用来保护隐私，敏感数据请使用加密。
为什么中文编码后变长了？
一个中文字符按 UTF-8 占 3 个字节，Base64 再把每 3 个字节编码成 4 个字符，因此中文内容会明显变长，属于正常现象。
URL-safe Base64 和普通 Base64 有什么区别？
普通 Base64 用 + 与 /，这两个字符在 URL 里有特殊含义；URL-safe 变体把 + 换成 -、/ 换成 _，并去掉末尾的 = 补位，方便直接放进网址或文件名。
编码解码会上传内容吗？
不会。全部转换在浏览器本地完成，文本与文件都不会发送到服务器。
