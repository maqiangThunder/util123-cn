常见问题

UUID 和 GUID 是一回事吗？
基本上是。GUID（全局唯一标识符）是微软对 UUID 的叫法，两者格式与含义一致，都是 128 位、通常写成 8-4-4-4-12 共 32 个十六进制字符加 4 个连字符的形式。
生成的 UUID 会重复吗？
UUID v4 有 122 位随机位，理论上可能重复但概率极低，低到实际使用中可以忽略，因此被广泛用作数据库主键、请求 ID、会话 ID 等唯一标识。
UUID v4 是随机生成的吗？
是的。UUID v4 几乎全部由随机数构成，本工具使用浏览器的安全随机源（crypto.getRandomValues）生成，而不是普通的伪随机数，因此更适合作为不可预测的标识使用。
生成会上传我的数据吗？
不会。UUID 完全在你的浏览器本地生成，不会有任何数据被发送到服务器。
