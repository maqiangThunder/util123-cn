常见问题

支持哪些 SQL 方言？
格式化器用语义无关的关键字切分，常见 MySQL / PostgreSQL / SQL Server / Oracle 的主句（SELECT、INSERT、UPDATE、DELETE、JOIN、WHERE、GROUP BY、ORDER BY 等）都会被换行并大写。
会改动我的 SQL 语义吗？
不会。只调整空白、换行和关键字大小写，不改变字段、表名、条件和字符串内容。
SQL 会上传吗？
不会。格式化完全在浏览器本地完成，SQL 不会发送到任何服务器。
