使用提示
· 二维码内容越短，图案越简单越好扫；网址建议先用短链。
· 深色前景 + 浅色背景对比度最高，扫描成功率也最高。
· 需要印刷时请下载 PNG 后按原始尺寸放大，或用 ≥ 512px 的显示尺寸导出。

常见问题

二维码容错等级选哪个好？
一般选 M（约 15% 容错）即可；二维码会印在容易磨损的位置或需要贴 logo 时，选 Q（25%）或 H（30%）更稳，代价是同样内容下图案更密集。
生成的二维码会过期吗？
不会。这里是直接把你的内容编码进二维码图案本身，不含任何跳转短链，扫出来就是原始内容，永久有效。
扫码扫不出来怎么办？
常见原因是前景与背景对比度太低（请用深色前景 + 浅色背景），或图案太小。建议显示尺寸不小于 200×200 像素，并在四周保留空白。
生成二维码会上传我的内容吗？
不会。二维码在浏览器本地由 JavaScript 实时生成，输入的内容不会发送到服务器。
