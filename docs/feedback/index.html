常见问题

如何反馈 Bug 或建议新工具？
在本页表单里选择反馈类型、填写内容与（选填的）联系方式，点「提交反馈」即可。提交后我们会自动收到邮件通知，无需你自己发邮件。
反馈 Bug 时提供什么信息最有帮助？
最好包含：使用的工具页面、输入的内容、期望结果与实际结果、浏览器与设备（如 iPhone Safari / Windows Chrome），必要时附截图。
反馈会公开吗？
不会。反馈内容仅用于改进工具，不会公开你的邮箱或其他个人信息。
