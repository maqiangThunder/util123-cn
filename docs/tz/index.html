常见问题

输入的时间按哪个时区算？
按你当前设备的本地时区换算。下方结果会显示同一时刻在其它城市对应的当地时间，方便约跨城 / 跨国会议或联系朋友。
为什么夏令时有时差对不上？
本工具使用的是浏览器内置的 IANA 时区数据库，已包含各地夏令时规则，结果就是该城市当下的真实本地时间，无需手动加减。
转换会上传时间吗？
不会。换算完全在浏览器本地完成，输入的时间不会发送到服务器。
