图片 Base64

上传或拖拽图片生成 DataURL / Base64，也可把 Base64 还原成图片预览下载，附带体积对比与 img 标签、CSS 写法。纯前端运行，图片不上传。

转换方向
选择图片
点击选择 或把图片拖到这里 支持 PNG / JPEG / GIF / WebP / SVG 等，图片不上传
DataURL（含 data:image/... 前缀）
纯 Base64（不含前缀）
选择一张图片开始转换。
粘贴 Base64 / DataURL （可带或不带 data:image 前缀）
粘贴 Base64 后点击「解析为图片」。

常见问题

图片转成 Base64 有什么用？
把图片编码成 Base64 后，可以直接内嵌进 HTML、CSS 或 JSON 里，无需额外请求图片文件，适合小图标、邮件模板、需要单文件交付的场景。缺点是体积会比原图大约三分之一。
为什么 Base64 比原图片大？
Base64 用 4 个可打印字符表示 3 个字节，因此编码后体积约为原始二进制的 1.33 倍。再加上 DataURL 前缀，整体会比原文件更大一些，所以不建议用它来传输大图。
Base64 转图片支持哪些格式？
支持常见的图片类型，包括 PNG、JPEG、GIF、WebP、BMP、SVG 等。粘贴可直接识别的图片 Base64 或完整 DataURL 即可预览，工具会自动识别格式。
图片会上传到服务器吗？
不会。图片的读取、编码与还原全部在你的浏览器本地完成，图片文件不会被上传。
