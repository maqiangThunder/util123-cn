常见问题

温度换算为什么特殊？

摄氏、华氏、开尔文之间不是简单倍数关系：℉ = ℃ × 9/5 + 32，K = ℃ + 273.15。工具已自动按公式处理。

数据存储按什么进制？

按常见的 1024 进制换算：1 KB = 1024 B，1 MB = 1024 KB，以此类推。硬盘厂商标注的 GB 通常按 1000 进制，会比这里算出的小。

数据会上传吗？

不会。换算完全在浏览器本地完成，不发送任何数据。
