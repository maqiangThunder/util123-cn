常见问题

全角和半角有什么区别？

半角是标准 ASCII 宽度（如 A、1、(），全角是占两个半角宽度的全宽字符（如 Ａ、１、（），常见于中文排版与日系系统。

转换会上传我的文本吗？

不会。全部在浏览器本地完成，不发送任何数据。
