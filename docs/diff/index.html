常见问题

文本差异对比是怎么工作的？
工具把两段文本按换行拆成一行行，用最长公共子序列算法逐行比对，标出只出现在左边（删除）、只出现在右边（新增）以及两边都有的行，并在左侧显示原始行号、右侧显示修改后的行号。
支持多大的文本？
常规的配置、代码、文档片段都没问题。为控制内存与速度，当待比对区域的规模过大时，工具会退化为整体「删除 + 新增」的粗略对比，建议单次控制在几千行以内以获得精细结果。
可以忽略大小写或空格差异吗？
可以。勾选「忽略大小写」后，A 与 a 视为相同；勾选「忽略行首尾空白」后，行首尾的空格、制表符不影响比对结果。原始内容仍按原样显示，只是比较时做了归一化。
对比会上传我的文本吗？
不会。所有比对都在浏览器本地完成，文本不会发送到任何服务器。
