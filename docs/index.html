常见问题

util123 是什么？
util123（util123.cn）是一个免费的在线小工具集合，提供 JSON 格式化与校验、公网 IP 查询、时间戳转换、二维码生成、密码生成、Base64 编解码、URL 编解码、哈希计算（MD5/SHA）、正则表达式测试、进制转换、文本差异对比、Unicode 转换、颜色转换、图片转 Base64、UUID 生成、m3u8 视频播放等纯前端工具，后续会继续打磨上架更多实用小工具。
使用需要注册或付费吗？
不需要。所有工具打开网页即可使用，完全免费，无需注册、登录或安装任何插件。
我粘贴的数据会被上传到服务器吗？
不会。JSON 格式化、转换、对比、编码解码、哈希计算等处理全部在你的浏览器本地完成；IP 查询由浏览器直接调用公开接口获取出口 IP，本站服务器不留存你的数据。
手机上能用吗？
可以。所有工具页面都做了移动端适配，用手机浏览器打开即可正常使用。
util123 后续还会增加哪些工具？
方向是「小而美」：每个工具只做一件事并做到足够好，打磨好了就上架，不堆砌功能。
