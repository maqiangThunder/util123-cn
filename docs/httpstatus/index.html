常见问题

HTTP 状态码分几类？

五类：1xx 信息提示、2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务端错误。常见的 200 成功、301 永久重定向、404 未找到、500 服务器内部错误分属其中。

404 和 502 有什么区别？

404 是服务器明确告知「资源不存在」，先查请求路径；502 是网关/反代后面的服务无有效响应，要查后端进程是否存活、上游日志报什么错。

数据会上传吗？

不会。搜索与浏览完全在浏览器本地完成，不发送任何数据。
