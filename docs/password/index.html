常见问题

密码多长算安全？
在包含大小写字母、数字和符号的前提下，12 位以上比较稳妥，重要账号建议 16 位以上。长度比复杂度更重要。
生成的密码会被记录吗？
不会。密码由浏览器内置的密码学安全随机数（crypto.getRandomValues）在本地生成，不经过服务器，刷新页面即消失。
为什么要排除「易混字符」？
0 与 O、1 与 l 与 I 在手写或某些字体下很难区分，抄写或手工输入密码时容易出错，排除后可以少犯错。
预估破解时间是怎么算的？
按信息熵「密码长度 × log2(字符集大小)」估算组合数，再假设攻击者每秒尝试 1000 亿次（离线暴力破解的高强度假设），取平均值即尝试一半组合所需的时间。
