常见问题

CSV 的第一行是表头吗？
是的。CSV 转 JSON 时第一行作字段名，后续每行生成一个对象；若第一行就是数据，键会是 c1、c2… 默认列名。
支持带引号的字段吗？
支持。双引号包裹的字段里，逗号、换行视为内容；连续两个双引号表示一个双引号字符，符合常见 CSV 约定。
数据会上传吗？
不会。转换完全在浏览器本地完成，文本不会发送到任何服务器。
