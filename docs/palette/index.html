常见问题

互补色有什么用？
互补色在色环上相距 180°，对比强烈，常用于按钮、警示或需要突出强调的元素，让主体一眼被注意到。
类比色适合什么场景？
类比色在色环上相邻（如色相 ±30°），搭配和谐自然，适合做渐变、插画和整体风格统一的界面。
生成的颜色会被上传吗？
不会。所有配色计算都在浏览器本地完成，颜色不会发送到任何服务器。
