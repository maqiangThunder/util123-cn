常见问题

这个域名解析工具是怎么查到记录的？
工具在你的浏览器里直接调用公共的 DNS-over-HTTPS（DoH）服务解析域名，不经过本站服务器。默认「自动」模式优先使用阿里、腾讯 DoH（国内直连可用），失败会自动切换到 Google / Cloudflare；也可以手动指定解析服务。
「全部记录」是怎么查的？
会同时查询 A、AAAA、CNAME、MX、TXT、NS、SOA 七种类型，把结果合并成一张表格，按类型排序展示，方便一次性看清一个域名的完整解析情况。
A 记录和 CNAME 有什么区别？
A 记录把域名指向一个 IPv4 地址，AAAA 指向 IPv6；CNAME 是别名，把一个域名指向另一个域名。MX 是邮件服务器记录，TXT 常用于校验域名所有权。
为什么有时查不到记录？
可能是该域名确实没有对应类型的记录、域名不存在（NXDOMAIN），或你的网络无法访问所选的 DoH 服务——可以在「解析服务」里换一个再试。
