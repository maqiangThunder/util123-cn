常见问题

m3u8 是什么？
m3u8 是 HLS（HTTP Live Streaming）协议的播放列表文件，常用于直播和点播视频流。本工具粘贴 m3u8 地址即可在浏览器直接播放，无需下载客户端。
为什么有的视频加载失败？
多是因为视频源站禁止跨域（CORS）或需要鉴权，浏览器出于安全策略无法拉取视频分片。这属于源站限制，并非工具本身的问题；换一个允许跨域的公开流地址通常即可正常播放。
支持哪些浏览器？
Chrome、Edge、Firefox 等通过内置 hls.js 播放；Safari 与大部分 iOS 设备原生支持 HLS，可直接播放。主流现代浏览器均可使用。
需要安装插件或注册吗？
不需要。打开网页即可使用，无需注册、登录或安装任何插件；播放所需的 hls.js 随页面一同加载。
