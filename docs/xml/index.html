常见问题

这个 XML 格式化工具会把我的数据上传吗？
不会。所有解析、美化、压缩都在你的浏览器本地完成，XML 文本不会发送到任何服务器。
美化后的 XML 为什么多了一行声明？
为了让结果成为标准 XML 文件，美化时会自动在开头补上 <?xml version="1.0" encoding="UTF-8"?> 声明。不想要可手动删掉那一行。
XML 报错了怎么看？
点「校验」后，工具用浏览器解析器检查语法，并在状态栏给出错误信息（多数浏览器会附带出错的大致行号）。
