User-Agent 解析

粘贴一段 UA 字符串，立即识别浏览器、操作系统与设备类型。排查兼容性、看访问日志随手用。纯前端，数据不出浏览器。


    

  


  

    
常见问题

    
解析准确吗？
基于常见 UA 特征规则匹配，覆盖主流浏览器与系统；非常见或高度定制的 UA 可能识别不全，仅供参考。

    
解析会上传 UA 吗？
不会。全部在浏览器本地完成，不发送任何数据。
